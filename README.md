# Two Bob Enterprises Website

Fast static website redesign for Two Bob Enterprises.

## Stack

HTML, CSS and vanilla JavaScript.

No framework and no runtime dependencies. The site uses responsive CSS, lightweight interactions and reduced motion support.

## Brand

Primary green: #28963D
Accent lime: #7CCF22
Charcoal: #504C4B

## Run

Open index.html directly or serve the folder with any static web server.
